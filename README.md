# Job_Analysis-PowerBI
Power BI data analysis project exploring job salaries, job roles, employment trends, and compensation patterns.

## Project Overview

This project analyzes job market data using Power BI to understand
salary patterns, job roles, locations, experience levels, and other
factors that influence compensation.

The project demonstrates how raw job data can be transformed into
interactive business insights using Power Query, DAX, and Power BI.

## Business Questions

- Which job roles have the highest average salaries?
- Which job roles have the lowest average salaries?
- How does salary vary by experience level?
- Which locations offer the highest salaries?
- How does salary vary across employment types?
- Which companies offer the highest salaries?
- What is the distribution of salaries across jobs?
- How does experience relate to salary?
- Which job categories have the most opportunities?
- What percentage of jobs fall into different salary ranges?

## Key KPIs

- Total Jobs
- Average Salary
- Minimum Salary
- Maximum Salary
- Average Experience
- Number of Job Roles
- Number of Companies

## Data Preparation

Data was cleaned and transformed using Power Query.

Steps included:

- Removing duplicates
- Handling missing values
- Cleaning text fields
- Converting salary fields to numerical values
- Creating salary ranges
- Standardizing job titles and categories
- Checking data types
